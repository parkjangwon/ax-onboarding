# [Runbook 04] 브라우저 자동화 E2E 테스트 및 결함 식별

웹 화면에서 발생하는 UI 이상, 폼 유효성 검증 실패, 비동기 호출 지연 등의 결함을 브라우저를 직접 띄워 재현하고 검증할 때 사용합니다.

## 실행 규칙
- 테스트 계정으로만 수행하며, 운영 데이터의 삭제/변조를 수반하는 액션은 사전 확인을 거칩니다.
- 콘솔 에러(F12 Console Log) 및 네트워크 실패(4xx/5xx HTTP Status)를 반드시 캡처합니다.

## 에이전트 자율 실행 절차 (Autonomous Execution Flow)
사용자가 "화면이 이상해", "버튼이 안 눌려", "UI 깨지는 거 확인해줘"라고 요청하면, 에이전트는 브라우저를 직접 띄워 아래 순서대로 진단합니다:

1. **브라우저 구동 및 재현**: Playwright / Browser MCP를 가동하여 제보된 시나리오대로 화면을 조작합니다.
2. **콘솔 및 네트워크 오류 수집**: 재현 과정에서 발생하는 브라우저 콘솔 에러(F12) 및 네트워크 실패(4xx/5xx)를 캡처합니다.
3. **결함 보고**: 이상 현상이 일어난 화면의 스크린샷과 프론트엔드/API 결함 원인을 보고합니다.

> 💬 **사용자 발화 예시**: "로그인 페이지에서 특정 브라우저로 접속 시 버튼 안 눌리는 현상 재현해서 원인 좀 찾아줘."
