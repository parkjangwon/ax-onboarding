# [Runbook 04] 브라우저 자동화 E2E 테스트 및 결함 식별

웹 화면에서 발생하는 UI 이상, 폼 유효성 검증 실패, 비동기 호출 지연 등의 결함을 브라우저를 직접 띄워 재현하고 검증할 때 사용합니다.

## 실행 규칙
- 테스트 계정으로만 수행하며, 운영 데이터의 삭제/변조를 수반하는 액션은 사전 확인을 거칩니다.
- 콘솔 에러(F12 Console Log) 및 네트워크 실패(4xx/5xx HTTP Status)를 반드시 캡처합니다.

## 에이전트 지시 프롬프트

```text
@runbooks/04-browser-e2e.md

[테스트 대상]
- URL: {테스트 대상 웹페이지 주소}
- 재현 순서:
  1. {로그인 또는 페이지 진입}
  2. {특정 메뉴 이동}
  3. {버튼 클릭 또는 폼 입력}

[요청 사항]
1. Playwright / Browser MCP를 구동하여 위 순서대로 브라우저를 조작해줘.
2. 재현 중 발생하는 브라우저 콘솔 에러 및 네트워크 요청 실패를 수집해줘.
3. 이상 현상이 발생하는 화면의 스크린샷을 저장하고 결함 원인을 보고해줘.
```
