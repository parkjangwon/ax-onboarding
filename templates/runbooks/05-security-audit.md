# [Runbook 05] 배포 전 보안 위협 및 하드코딩 시크릿 점검

코드 커밋 및 릴리즈 배포 전, 보안 취약점과 자격 증명 누출 위험을 선제적으로 차단하기 위한 보안 점검 절차서입니다.

## 점검 대상 항목
1. **하드코딩된 자격 증명**: API Key, DB 비밀번호, SSH Private Key, AWS 시크릿
2. **권한 및 접근 통제**: 인증 우회 가능성, 불필요한 ADMIN 권한 부여 여부
3. **OWASP Top 10**: SQL Injection(동적 쿼리 바인딩 확인), XSS, 안전하지 않은 역직렬화
4. **개인정보(PII) 누출**: 주민등록번호, 전화번호, 이메일 등이 암호화 없이 로그나 화면에 노출되는지 여부

## 에이전트 지시 프롬프트

```text
@runbooks/05-security-audit.md

[점검 대상]
- 대상 브랜치/커밋 또는 수정된 파일 목록

[요청 사항]
1. 수정된 코드 내에 하드코딩된 비밀번호, API 토큰, 사내 서버 IP가 평문으로 포함되었는지 정적 분석해줘.
2. 외부 사용자 입력값이 DB 쿼리나 쉘 명령어에 직접 연결(String Concatenation)된 곳이 있는지 확인해줘.
3. 개인정보(PII)가 로그 파일(catalina.out, application.log 등)에 원문 그대로 찍히는 지점이 있는지 감사해줘.
4. 발견된 취약점의 위험도(High/Medium/Low)와 권장 패치 코드를 리포트해줘.
```
