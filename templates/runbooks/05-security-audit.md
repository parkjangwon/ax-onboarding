# [Runbook 05] 배포 전 보안 위협 및 하드코딩 시크릿 점검

코드 커밋 및 릴리즈 배포 전, 보안 취약점과 자격 증명 누출 위험을 선제적으로 차단하기 위한 보안 점검 절차서입니다.

## 점검 대상 항목
1. **하드코딩된 자격 증명**: API Key, DB 비밀번호, SSH Private Key, AWS 시크릿
2. **권한 및 접근 통제**: 인증 우회 가능성, 불필요한 ADMIN 권한 부여 여부
3. **OWASP Top 10**: SQL Injection(동적 쿼리 바인딩 확인), XSS, 안전하지 않은 역직렬화
4. **개인정보(PII) 누출**: 주민등록번호, 전화번호, 이메일 등이 암호화 없이 로그나 화면에 노출되는지 여부

## 에이전트 자율 실행 절차 (Autonomous Execution Flow)
사용자가 "커밋 전에 보안 점검해줘", "시크릿이나 취약점 있나 봐줘"라고 요청하면, 에이전트는 아래 4가지 항목을 정적 분석합니다:

1. **하드코딩 시크릿 전수 조사**: 수정된 코드 내에 비밀번호, API Key, 사내 서버 IP 등이 평문으로 포함되었는지 검사합니다.
2. **동적 쿼리/명령어 취약점 점검**: 외부 입력값이 SQL 쿼리나 쉘 명령어에 직접 연결(Concatenation)된 보안 홀을 점검합니다.
3. **개인정보(PII) 평문 로깅 점검**: 주민번호, 전화번호, 이메일 등이 마스킹 없이 로그에 출력되는지 확인합니다.
4. **결과 및 패치 리포트**: 발견된 위험의 심각도(High/Medium/Low)와 안전한 수정 코드를 제시합니다.

> 💬 **사용자 발화 예시**: "이번에 작업한 브랜치 커밋하기 전에 하드코딩된 키나 보안 취약점 없는지 점검해줘."
